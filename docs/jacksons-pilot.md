# Jacksons Retreat — FastKiwi Live Lab

## Objective

Prove one complete production workflow before broad hardware rollout:

**Booking -> Map -> ANPR -> Access -> Dashboard**

## Stage 1 — Digital twin / Park Map

Map entry/exit, kiosk, cabins, RV/tent sites, Services Building, kitchen/lounge, toilets/showers, laundry, sauna/hot tubs, massage, EV, dump station, glow-worm locations, waterfall track, quartz-mine track, parking, emergency points and future vending/robot cafe.

Guest flow: booking number or QR -> reservation -> allocated unit/site -> route -> included facilities -> optional paid facilities -> checkout/dump guidance.

## Stage 2 — Entry / exit

Entry and exit ANPR, boom gate integration, reservation-linked plate validity, arrival/exit events and the fallback chain ANPR -> PIN -> remote open -> physical emergency override.

## Stage 3 — Self check-in

Existing booking: lookup -> balance check -> plate -> activate credentials -> personalized map.

Walk-in: availability -> select -> payment -> booking -> access -> gate.

## Stage 4 — Facility pilot

Start with sauna and hot tubs: QR/PIN -> entitlement -> included or payment -> timed access -> revenue log.

## Measures

Self-service arrival %, median check-in time, gate recognition success, manual interventions, support contacts, ancillary revenue per occupied night, access failures and uptime.
